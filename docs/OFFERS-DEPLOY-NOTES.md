# First Offers release scope

`/offers/painel-ripado` is the first production implementation of the E-com.casa Offers Engine. It keeps the central product/cart/checkout/XPayments stack, uses a conversion-focused page structure derived from a public commercial reference, adds licensed/free editorial video slots rather than copying proprietary media, and resolves GEO context through the existing E-com.casa country engine.

The release intentionally keeps the catalogue saleability gate active: demo/staged products may be presented for layout validation but cannot create a payable order until supplier, stock and compliance requirements are approved.
